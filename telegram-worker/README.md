# Підключення форми сайту до Telegram

Сайт — статичний (GitHub Pages), тому форма сама по собі нікуди не
відправляється. `worker.js` — маленький безкоштовний "місток" на
Cloudflare Workers, який приймає дані з форми і пересилає їх у Telegram.

## Крок 1. Створити бота
1. У Telegram відкрийте **@BotFather** → `/newbot` → дайте імʼя.
2. Отримаєте **BOT_TOKEN** (виглядає як `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxx`).
3. Напишіть новому боту будь-яке повідомлення (напр. "привіт") — це потрібно,
   щоб бот "побачив" ваш чат.

## Крок 2. Дізнатись CHAT_ID
Відкрийте в браузері:
```
https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/getUpdates
```
У відповіді знайдіть `"chat":{"id": 123456789, ...}` — це і є **CHAT_ID**.

(Якщо хочете, щоб заявки падали в груповий чат — додайте бота в групу,
напишіть там щось, і id групи буде від'ємним числом типу `-100123456789`.)

## Крок 3. Задеплоїти Worker на Cloudflare (безкоштовно)
1. Зареєструйтесь на https://dash.cloudflare.com (безкоштовний план).
2. Workers & Pages → Create → Create Worker.
3. Дайте назву, напр. `sensoryiq-contact-form`.
4. Відкрийте редактор коду Worker'а, вставте вміст файлу `worker.js`
   з цієї теки. Deploy.
5. Settings → Variables and Secrets → додайте:
   - `BOT_TOKEN` = токен з кроку 1
   - `CHAT_ID` = id з кроку 2
   - `ALLOWED_ORIGIN` = адреса вашого сайту, напр. `https://username.github.io`
     (або `*` на час тестування)
6. Збережіть і задеплойте ще раз, якщо просить.

Після деплою Cloudflare дасть вам URL типу:
```
https://sensoryiq-contact-form.ВАШ-SUBDOMAIN.workers.dev
```

## Крок 4. Підключити URL до сайту
У файлі `script.js` знайдіть рядок:
```js
const TELEGRAM_ENDPOINT = 'https://sensoryiq-contact-form.YOUR-SUBDOMAIN.workers.dev';
```
і замініть на URL, який дав Cloudflare. Все, форма готова — заявки
приходитимуть в Telegram миттєво.

## Як потім перемкнути на дані іншої людини/бізнесу
Є два способи — можна користуватись будь-яким:

- **Найпростіше:** у Cloudflare Workers → Settings → Variables змініть
  значення `CHAT_ID` (і за потреби `BOT_TOKEN`) на нові. Код і сайт
  чіпати не треба — заявки почнуть приходити в новий чат одразу.

- **Якщо потрібно тримати кількох клієнтів одночасно:** задеплойте ще
  один Worker з тим самим кодом, але іншими `BOT_TOKEN`/`CHAT_ID`, і в
  `script.js` того сайту вкажіть його власний `TELEGRAM_ENDPOINT`.

## Перевірка номера телефону
Форма (і на сайті, і у Worker'і — для надійності) перевіряє, що поле
"Номер телефону" містить 10–15 цифр (дозволені `+`, пробіли, дужки,
тире) і що це не набір з однакових цифр. Явно некоректні значення
(букви, "111111111", короткі набори типу "123") форма відхиляє і
показує повідомлення про помилку, не надсилаючи заявку.
