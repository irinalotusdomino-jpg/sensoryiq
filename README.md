# sensoryIQ — сайт-візитка

Стильний односторінковий сайт для дитячого центру розвитку sensoryIQ (Київ,
ЖК Варшавський), українською. Чистий HTML/CSS/JS — без збірки, без
залежностей. Готовий для GitHub Pages, з базовим SEO та мета-тегами для
Google і соцмереж.

## Структура

```
index.html        — розмітка сторінки, мета-теги, JSON-LD для Google
style.css         — стилі, кольори, анімації
script.js         — інтерактив (курсор-орб, скрол-анімації, відео, лічильники)
assets/logo.png   — ваш логотип (з прозорим фоном)
assets/favicon.*  — іконки вкладки браузера різних розмірів
assets/posters/   — кадри-обкладинки для відео (показуються до натискання play)
videos/           — 6 реальних кліпів з ваших Instagram-хайлайтів
robots.txt        — дозволяє пошуковим ботам сканувати сайт
sitemap.xml       — карта сайту для Google Search Console
```

## Відео

У розділі "Відео" зараз 6 реальних кліпів, узятих з ваших хайлайтів:

| Файл                        | Тема           |
|-----------------------------|----------------|
| videos/rannij-rozvytok.mp4  | Ранній розвиток|
| videos/logopediya.mp4       | Логопедія      |
| videos/hatha-yoga.mp4       | Хатха-йога     |
| videos/fly-yoga.mp4         | Флай-йога      |
| videos/aktorstvo.mp4        | Акторство      |
| videos/anglijska.mp4        | Англійська мова|

Щоб замінити будь-який кліп — покладіть новий файл під тим самим іменем
(стиснутий: ширина ~480px, H.264, через [HandBrake](https://handbrake.fr/)
або команду `ffmpeg -i input.mp4 -vf scale=480:-2 -crf 26 output.mp4`).
Якщо хочете додати більше кліпів — скопіюйте блок `.video-card` в
`index.html` і додайте новий файл у `videos/`.

## Логотип і фавікони

`assets/logo.png` — ваш логотип із прибраним білим фоном (прозорий PNG),
використовується у шапці сайту та футері. `assets/favicon.*` — іконки
вкладки браузера, згенеровані з логотипу. Щоб замінити лого — покладіть
новий файл із тим самим іменем `assets/logo.png`.

## SEO — що вже налаштовано

- Заголовок, опис, ключові слова під запити на кшталт "сенсорна кімната
  Київ", "логопед Київ", "дитячий центр розвитку".
- Open Graph та Twitter-теги — щоб посилання на сайт красиво виглядало
  при пересиланні в месенджерах і соцмережах.
- JSON-LD розмітка типу `ChildCare` — допомагає Google показувати назву,
  адресу й телефон прямо в результатах пошуку.
- `robots.txt` і `sitemap.xml` — щоб Google міг проіндексувати сайт.

**Важливо:** у мета-тегах (canonical, og:url, og:image, sitemap.xml) зараз
прописано `https://sensoryiq.github.io/` як приклад адреси. Коли
опублікуєте сайт (крок нижче) і дізнаєтесь його реальну адресу — замініть
цей URL у файлах `index.html`, `robots.txt` і `sitemap.xml` (пошук за
`sensoryiq.github.io`). Також після публікації безкоштовно додайте сайт у
[Google Search Console](https://search.google.com/search-console) і
надішліть `sitemap.xml` — це прискорить появу сайту в пошуку.

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub, наприклад `sensoryiq-site`.
2. Завантажте туди всі файли з цієї папки (`index.html`, `style.css`,
   `script.js`, `robots.txt`, `sitemap.xml`, папки `assets/` та `videos/`).
3. У репозиторії відкрийте **Settings → Pages**.
4. У розділі "Build and deployment" оберіть **Source: Deploy from a branch**,
   гілку `main` і папку `/ (root)`. Натисніть **Save**.
5. Через 1–2 хвилини сайт буде доступний за адресою:
   `https://ВАШ-НІК.github.io/sensoryiq-site/`

Якщо хочете власний домен — додайте його у тому ж розділі Pages (поле
"Custom domain") і налаштуйте DNS у реєстратора домену (CNAME на
`ВАШ-НІК.github.io`).

## Локальний перегляд

Просто відкрийте `index.html` у браузері — жоден сервер не потрібен.
